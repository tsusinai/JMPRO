# Bilibili 网络梗百科全书

## 经典弹幕梗

### 你币没了
当 UP 主说了不符合主流价值观或招黑的内容时，弹幕会刷"你币没了"，意为"你的硬币我要取消了"。后来演变为任何让人不爽的操作都用此表达。例句："三连骗局，你币没了！"

### 下次一定
UP 主求三连（点赞、投币、收藏）时，观众白嫖的经典回复。意为"下次再投币"，实际上永远不会投。是 B 站最经典的鸽王语录。

### 梦开始的地方
指某个经典视频或系列的第一期，对粉丝有特殊纪念意义。也用来指代某个梗或系列的起源。例句："这个视频是鬼畜区的梦开始的地方。"

### 新人千万不要看
弹幕常用骗新人入坑的句式，实际上是在安利。例句："新人千万不要看这个UP，看了就出不来了。"

### 建议改为 / 建议改成
弹幕梗，用来吐槽视频标题不够吸引人，弹幕会帮 UP 主想一个更标题党的标题。格式："建议改为：XXX"。源自 UP 主"吃素的狮子"的视频。

### 你醒啦 / 你醒了
源自游戏《只狼》的梗，后演变为任何"从昏迷/死亡中醒来"场景的通用弹幕。

### 前方高能
源自《机动战士高达》的"前方高能反应"，B 站弹幕中最经典的高能预警，用来提醒后面有精彩/恐怖/刺激的内容。衍生出"前方核能""非战斗人员请撤离"等变体。

### 开口跪
形容某人一开口唱歌/说话就让人跪服，嗓音极好或反差极大。

### 战歌起
激动人心的 BGM 响起时刷的弹幕，表示高潮部分来了。经典战歌包括《βios》（罪恶王冠）、《Only My Railgun》（超电磁炮）等。

### 谢谢，有被笑到
阴阳怪气用语，表面上表示感谢，实际上表示并没有被逗笑。也可以真心使用。衍生："谢谢，有被冒犯到""谢谢，有被甜到"。

### 妙啊
配合竖大拇指表情，表示非常赞同或者对整活内容的赞叹。源自表情包文化。

### 禁止自娱自乐 / 禁止好活
弹幕对优质内容的调侃式"批评"，实际上是在夸。"禁止好活"意为"这活太好了，不许整这么好的活"。

## UP 主与鬼畜区

### 鬼畜
B 站特色视频类型，通过对视频/音频素材的重复、变速、调音、拼接来制作搞笑视频。B 站有专门的"鬼畜区"。

### 镇站之宝
指播放量极高、影响力极大、被公认为 B 站代表作的视频。如《【古筝】千本樱》、《Are You OK》等。

### 满分作文
对评论区文采飞扬的评论的赞美。B 站评论区常有用户写出长篇押韵的段子，被称为"满分作文"。

### 课代表
在评论区总结视频要点的热心用户。弹幕或评论常见"课代表来了""谢谢课代表"。

### 省流助手
在评论区简洁概括视频内容的人，帮不想看完整视频的人节省时间。格式："省流：XXX"。衍生出"省流侠""省流大师"。

### 狗头保命
说话后加上狗头表情（🐶），表示前面的话是开玩笑/反讽，不要当真。类似微博的狗头文化。

### 这个入是桂 / 注入灵魂
"这个人是要跪"的谐音，形容某事让人佩服得五体投地。"注入灵魂"指某个细节让整个作品有了灵魂。

### 咕咕咕 / 鸽了
UP 主拖更的代名词。鸽子叫声"咕咕咕"，所以拖更 = 放鸽子 = 鸽了。知名拖更 UP 主被称为"鸽王"。

### 肝 / 爆肝
拼命做某事，尤其指 UP 主熬夜爆肝更新视频。"肝"在中文网络语中从器官变成了动词，意为拼命干。例句："这期视频我肝了三天三夜。"

## 弹幕礼仪与社区文化

### 素质三连
弹幕中对不文明内容的抵制，常刷"素质三连举报"。也指一键三连（点赞+投币+收藏）。

### 空降成功 / 指挥部
弹幕中有人发时间戳（如"空降 03:25"）标记精彩内容的时间点。后来者"空降成功"表示按照指挥成功跳到了精彩部分。衍生出"空难"（跳到无聊片段）、"返航"（从头看）。

### 考古 / 考古队
在很久以前的老视频里刷弹幕/评论的行为。例句："2026 年来考古""考古队集合"。

### 无意冒犯 / 如有冒犯请见谅
B 站评论区常见的免责声明前缀，用于发表可能引起争议的观点。

### 你干嘛 ~ 哎哟
源自蔡徐坤《偶像练习生》中的台词，后成为鬼畜区经典素材。语调魔性，是 B 站最出圈的梗之一。

### 鸡你太美
蔡徐坤《只因你太美》的空耳，B 站现象级鬼畜素材，衍生出无数二创。因"鸡"谐音"只因"，也催生了大量鸡相关的二创。

## 弹幕互动游戏

### 选择你的英雄
弹幕在多个选项出现时刷，让人选择自己支持的一方或角色。源自游戏选人界面的梗。

### 我全都要
源自电影《九品芝麻官》徐锦江的经典台词，当面对多个好东西时表示全选。B 站弹幕万能句式。

### 小孩子才做选择，成年人全都要
上面"我全都要"的现代网络语版本。

## 2024-2026 年新梗

### 遥遥领先
源自华为发布会的"遥遥领先"，被广泛用于各种场合的调侃，表示某个东西实在太强了，没有对手。

### 尊嘟假嘟
"真的假的"的可爱发音变体，2024 年开始流行。经常配合卖萌表情使用。

### 哈基米
源自日语"蜂蜜"（はちみつ hachimitsu）的空耳，因一首猫猫视频 BGM 走红。常配猫咪视频，成为猫咪代名词。

### 命运的齿轮开始转动
用于某些重大事件的转折点描述，配伤感或励志 BGM。表示从那一刻起一切都不一样了。

### i人 / e人
源自 MBTI 人格测试的 Introvert（内向）和 Extrovert（外向），B 站年轻人常用来自我标签。"本 i 人表示社恐犯了""e 人狂喜"。

### 显眼包
指在群体中特别显眼、爱出风头的人（或动物）。略带调侃但多为善意。

### 遥遥领先 / 太强了
从华为延伸到所有"碾压级"优势场景的万能夸赞语。

### 精神状态良好
反讽用语，用于展示自己/他人的离谱行为。例句："我的精神状态：稳定发疯中"。

### 绝绝子
形容某事物好到极致，源自小红书语言体系，现已广泛渗透到 B 站弹幕和评论。

### yyds
"永远的神"的拼音首字母缩写，形容某人/某物是永恒的顶级存在。源自电竞圈，Uzi 的外号。

### xswl
"笑死我了"的拼音首字母缩写，B 站弹幕高频用语。

### awsl
"啊我死了"的拼音首字母缩写，形容被可爱/萌到不行了。源自 B 站虚拟主播文化。

### nsdd
"你说得对"的拼音首字母缩写。

### u1s1
"有一说一"的拼音首字母缩写，用于客观公正地评价某事。

## B 站特色文化

### 三连（点赞、投币、收藏）
B 站最核心的互动机制。UP 主通常在视频结尾"求三连"。硬币是 B 站虚拟货币，每天登录可领取。

### up主
B 站对视频创作者的称呼。知名 UP 主拥有大量粉丝，被称为"百大 UP 主"（B 站每年评选的 Top 100 创作者）。

### 充电
B 站用户向 UP 主付费支持的方式，类似打赏。分为"电池充电"（小额）和"包月充电"（持续支持）。

### 大会员
B 站的付费会员服务，可观看付费番剧、享受高清画质等特权。"到底要不要开大会员"是 B 站用户的经典纠结。

### 入站必刷
B 站官方精选的必看经典视频合集，新用户入门指南。入站必刷视频通常包括鬼畜神作、镇站之宝等。

### 弹幕池
每条视频的弹幕总数有上限，称为"弹幕池"。热门视频的弹幕池满了后，旧的弹幕会被清除，只保留最新的。

### B站只有两个区：鬼畜区和鬼畜素材区
经典自嘲梗，意思是 B 站几乎所有内容都可以被做成鬼畜。形容 B 站鬼畜文化的无孔不入。

### 叔叔 / 阿姨
"叔叔"指 B 站 CEO 陈睿，用户对他的戏称。源自早期 B 站用户对管理层的亲切/调侃称呼。

### 蒙古上单
B 站传奇用户，因在 CEO 陈睿的动态下发出经典评论"你所热爱的就是你的生活"而一战成名，被认为是用户的嘴替和精神领袖。

### 小黑屋
B 站对违规用户的处罚公示区，违规用户会被展示在小黑屋页面供人围观。

## 二次元 / ACG 通用梗

### 战术后仰
表示被震惊到后仰的动作，源于周星驰电影。B 站表情包和弹幕常用。

### 你不对劲
当某人说了奇怪的话或做了奇怪的事时，弹幕刷"你不对劲""这位更是重量级"。表示怀疑对方有问题。

### 我有个朋友
委婉提问的经典开头句式，常用于尴尬问题。"我有个朋友想问问..."实际上就是自己想知道。

### 不会吧不会吧
阴阳怪气反问句式，表示难以置信或嘲讽。"不会真有人 XXX 吧？"

### 啊对对对
源自 B 站评论区对话，表示敷衍式赞同。语气不同可表示真心赞同或阴阳怪气。

### 这很合理 / 但代价是什么
前者表示某种离谱的解释居然说得通，后者追问某个好处背后的隐藏代价。

### 发生什么事了
经典问句，表示一脸茫然、不知道发生了什么。表情包常用。

### 差不多得了
劝人适可而止，别太过分。常用于弹幕劝阻钓鱼/引战言论。

### 不是哥们
表示震惊、无语的万能开头，2024-2025 年 B 站评论区高频用语。格式："不是哥们，你 XXX？"
