# 番剧与游戏百科全书

## 一、经典名作（2000年前奠基之作）

### 动画电影
- **《千与千寻》**(2001)：宫崎骏代表作，奥斯卡最佳动画长片，日本影史票房冠军（保持至2020年被《鬼灭之刃无限列车》超越）。讲述少女千寻误入神灵世界，通过劳动拯救变成猪的父母。主题：成长、贪婪、环保。
- **《幽灵公主》**(1997)：宫崎骏，人与自然冲突的史诗。少年阿席达卡被诅咒，卷入铁镇与森林神兽的战争。女主小桑（幽灵公主）由狼养大。
- **《龙猫》**(1988)：宫崎骏最温暖的作品，乡村姐妹与森林精灵龙猫的奇妙邂逅。龙猫成为吉卜力标志。
- **《天空之城》**(1986)：宫崎骏，飞行岛拉普达的冒险。少年巴鲁与少女希达追寻天空之城，对抗军方与海盗。
- **《阿基拉》**(1988)：大友克洋，赛博朋克里程碑。2019年新东京，暴走族少年获得超能力。影响《黑客帝国》等无数作品。
- **《攻壳机动队》**(1995)：押井守，赛博朋克哲学巅峰。草薙素子少佐追捕黑客"傀儡师"，探讨灵魂与躯壳的边界。

### 经典TV动画
- **《新世纪福音战士/EVA》**(1995)：庵野秀明，机甲+心理+宗教隐喻。14岁少年碇真嗣被迫驾驶EVA对抗使徒。角色全员心理创伤。绫波丽开创"三无少女"属性。
- **《星际牛仔》**(1998)：渡边信一郎，太空爵士风西部片。赏金猎人Spike、Jet、Faye、Ed在2071年太阳系的日常与宿命。配乐菅野洋子封神。
- **《机动战士高达》系列**(1979起)：富野由悠季，真实系机器人动画鼻祖。初代高达讲述阿姆罗驾驶RX-78-2对抗吉翁公国。后续SEED(2002)、00(2007)、水星的魔女(2022)等。
- **《美少女战士》**(1992)：武内直子，魔法少女变身战斗鼻祖。月野兔与伙伴们守护地球。"代表月亮消灭你"成为文化符号。

## 二、2000-2010年 黄金时代

### 少年热血三大漫
- **《海贼王/ONE PIECE》**(1999连载中)：尾田荣一郎，全球销量最高漫画。路飞要成为海贼王，寻找大秘宝ONE PIECE。伙伴：索隆、娜美、山治、乔巴、罗宾等。核心主题：自由、伙伴、梦想。动画东映制作，和之国篇后进入最终章。
- **《火影忍者》**(2002-2017)：岸本齐史，鸣人从吊车尾成为火影。佐助复仇、晓组织、忍界大战。核心：羁绊、传承、宽恕。续作《博人传》。
- **《死神/BLEACH》**(2004-2012, 2022千年血战篇)：久保带人，黑崎一护成为死神代理。斩魄刀、卍解、虚、破面。2022年千年血战篇动画高质量回归。

### 钢炼与神作
- **《钢之炼金术师FA》**(2009)：荒川弘，等价交换法则下的兄弟冒险。爱德华与阿尔冯斯寻找贤者之石恢复身体。人造人七宗罪。全球评分常年霸榜。
- **《反叛的鲁路修》**(2006-2008)：谷口悟朗+大河内一楼，被流放王子鲁路修获得Geass绝对命令能力，化身Zero推翻神圣不列颠帝国。"错的不是我，是世界"名台词。
- **《天元突破 红莲螺岩》**(2007)：今石洋之，超级系机器人巅峰。西蒙从地底钻出到把银河系当飞镖扔。核心："你以为我是谁！""钻头是男人的浪漫"。
- **《CLANNAD》**(2007-2008)：Key社催泪巅峰。朋也与古河渚的校园恋爱、结婚、育儿。After Story篇公认"人生"教科书，催泪核弹。

### 现象级作品
- **《凉宫春日的忧郁》**(2006)：谷川流原作，京阿尼制作。SOS团团长凉宫春日无意识拥有改变世界能力。"我对普通人没兴趣，宇宙人未来人超能力者来找我"。
- **《魔法少女小圆》**(2011)：虚渊玄+新房昭之，颠覆魔法少女类型。可爱包装下的黑暗剧情。鹿目圆、晓美焰的时空轮回悲剧。第三集"学姐掉头"震惊业界。
- **《Fate/Stay Night》**(2006)与**《Fate/Zero》**(2011)：圣杯战争，七位英灵与御主争夺万能许愿机。阿尔托莉雅（Saber）成为型月看板娘。虚渊玄执笔Zero被称为"爱的战士"。

## 三、2011-2020年 新时代

### 现象级爆款
- **《进击的巨人》**(2013-2023)：谏山创，人类被巨人围困于三重城墙内。艾伦追求自由，最终走向极端。立体机动装置战斗动画水准顶级。马莱篇后主题升级为种族仇恨与战争。
- **《鬼灭之刃》**(2019-至今)：吾峠呼世晴，大正时代炭治郎为变成鬼的妹妹祢豆子踏上斩鬼之路。ufotable动画制作封神。剧场版无限列车打破日本影史纪录。
- **《咒术回战》**(2020-至今)：芥见下下，咒术师对抗诅咒。虎杖悠仁吞下宿傩手指成为容器。五条悟天花板战力。涉谷事变篇大转折。MAPPA制作。
- **《刀剑神域》**(2012)：川原砾，VRMMO死亡游戏。桐人被困SAO，通关才能退出。掀起异世界轻改浪潮。"星爆气流斩"双刀流名场面。

### 日常/治愈系
- **《摇曳露营》**(2018-2024)：少女们的冬日露营日常。芝麻凛和抚子。温暖治愈，带动日本露营热潮。BGM神。
- **《轻音少女》**(2009-2011)：京阿尼，樱高轻音部五人组喝茶吃点心偶尔练习。呆唯、澪、律、紬、梓。"强国源泉"。
- **《紫罗兰永恒花园》**(2018)：京阿尼，自动手记人偶薇尔莉特学习"爱"的含义。"少佐，我爱你"。

### 恋爱喜剧
- **《辉夜大小姐想让我告白》**(2019-2023)：赤坂明，学生会会长与副会长互相暗恋却傲娇不肯先表白的头脑战。藤原书记舞魔性出圈。A1-Pictures制作。
- **《五等分的新娘》**(2019-2021)：春场葱，贫穷高中生风太郎成为五胞胎姐妹的家庭教师。五选一股指大战。
- **《Re:从零开始的异世界生活》**(2016-)：长月达平，菜月昴轮回系穿越到异世界。死亡回归能力，每次死亡重置。蕾姆告白名场面。白狐社制作。

### 运动番
- **《排球少年!!》**(2014-2020)：古馆春一，日向翔阳与影山飞雄"怪人速攻"。乌野高中排球部。IG制作，比赛分镜教科书级别。

## 四、2021-2026年 最新趋势

- **《芙莉莲》**(2023-)：山田钟人+阿部司，勇者队伍讨伐魔王后，精灵魔法使芙莉莲踏上"了解人类"的旅程。辛逝去后才开始真正了解他。MADHOUSE制作，氛围绝佳。
- **《我推的孩子》**(2023-)：赤坂明+横枪萌果，偶像生子+转生娱乐圈+复仇。星野爱被刺开场核弹级。YOASOBI《アイドル》主题曲破纪录。动画工房制作。
- **《迷宫饭》**(2024)：九井谅子，异世界美食番。冒险者莱欧斯在迷宫中烹饪魔物。严谨的生态设定。扳机社制作。
- **《孤独摇滚！》**(2022-)：滨路晶，社恐吉他手后藤一里（波奇）加入纽带乐队。CloverWorks制作，演出创意满分。带动原作和乐器销量暴涨。
- **《电锯人》**(2022-)：藤本树，少年淀治与电锯恶魔波奇塔融合成为电锯人。MAPPA制作，电影感十足。玛奇玛支配恶魔。藤本树独特的"精神病人"叙事。
- **《间谍过家家》**(2022-)：远藤达哉，间谍×杀手×读心超能力女孩组成虚假家庭。安妮亚表情包出圈。WIT+CloverWorks联合制作。

## 五、游戏知识

### 日式RPG
- **《最终幻想》系列**：Square Enix。FF7(1997)克劳德、蒂法、爱丽丝，重制版三部曲。FF14(2013)吉田直树拯救的MMORPG。FF16(2023)黑暗成人向。
- **《勇者斗恶龙》系列**：鸟山明人设。"日本国民RPG"。DQ11(2017)回归经典。DQ5选择新娘系统。
- **《女神异闻录/PERSONA》系列**：Atlus。P5(2016)雨宫莲率领心之怪盗团改心。时髦UI、Jazz BGM。人格面具=内心反抗意志。
- **《塞尔达传说》系列**：任天堂。旷野之息(2017)开放世界标杆。王国之泪(2023)究极手+通天术+倒转乾坤。
- **《异度神剑》系列**：Monolith。XB2(2017)焰/光双人格女主。XB3(2022)两个敌对国家的少年兵。

### 魂系与动作
- **《黑暗之魂》系列**：FromSoftware。火之将熄，不死人传火。宫崎英高的恶意：毒沼、宝箱怪、帕奇。骑士、咒术师、魔法师。
- **《艾尔登法环》**(2022)：宫崎英高+乔治RR马丁。褪色者修复艾尔登法环。开放世界魂系。女武神玛莲妮亚"我是玛莲妮亚，米凯拉的刀锋"。
- **《只狼》**(2019)：战国忍者只狼。打铁式拼刀战斗。"犹豫就会败北"。苇名一心最终BOSS教科书。
- **《怪物猎人》系列**：Capcom。狩猎大型怪物。14种武器：太刀、大剑、弓、双刀等。世界(2018)和崛起(2021)两代。Rise翔虫系统。资料片冰原/曙光。
- **《鬼泣》系列**：Capcom。恶魔猎人但丁。华丽连招动作游戏标杆。DMC5(2019)尼禄+V+但丁三主角。

### 任天堂
- **《超级马力欧》系列**：马力欧/马里奥。奥德赛(2017)帽子凯皮附身。马力欧赛车8豪华版NS销量冠军。马力欧惊奇(2023)。
- **《宝可梦》系列**：收集、训练、对战。朱/紫(2022)帕底亚地区开放世界。传说阿尔宙斯(2022)动作化。全球最高价值IP。
- **《动物森友会》**：2020年疫情期间全球现象。无人岛移居，还贷、装饰、串门。大头菜股市。
- **《任天堂明星大乱斗》**：全明星格斗。从马力欧到史蒂夫(我的世界)到索拉到萨菲罗斯。

- **《原神》**(2020)：miHoYo，开放世界抽卡RPG。提瓦特七国，元素反应系统。角色：荧/空(旅行者)、钟离、雷电将军、纳西妲等。年度更新六周一个版本。

- **《碧蓝档案》**(2021)：Nexon，师生题材。老师(Kivotos唯一成年人)指导学生。纱织、星野等。"为师很担心你"。

- **《蔚蓝档案/Blue Archive》**：同碧蓝档案。
- **《少女前线》系列**：散爆网络。枪械拟人战术。少前2追放(2023)。

### 竞技/电竞

### 游戏术语
- **Roguelike/Roguelite**：随机生成地图+永久死亡/部分升级保留。死亡细胞、哈迪斯。
- **银河城/Metroidvania**：探索驱动，获得新能力解锁新区域。空洞骑士、血污。
- **魂系/Soulslike**：高难度、死亡掉经验、篝火存档。黑魂、艾尔登法环。
- **抽卡/Gacha**：氪金随机获取角色/武器。原神、FGO。
- **开放世界**：无缝大地图自由探索。塞尔达、GTA、艾尔登法环。
- **MOD**：玩家自制修改。上古卷轴、我的世界MOD社区庞大。
- **Early Access/抢先体验**：未完成即发售，玩家参与开发过程。

## 六、B站流行梗百科

### 鬼畜区经典
- **哈基米**：源自日语"蜂蜜"（はちみつ/hachimitsu）的空耳。因一首猫咪跟着BGM扭动的视频爆火，配乐歌词"哈基米"被空耳成各种中文词。成为猫猫代名词，弹幕常刷"哈基米哈基米"。
- **大狗叫**：源自歌曲《你打不过我吧》的鬼畜，"大狗叫"是"打不过我吧"的空耳。配各种搞笑视频，表达一种"你能拿我怎样"的嚣张态度。
- **凑企鹅**：源自B站UP主"凑"（凑阿库娅的粉丝），因其头像和说话方式像企鹅而得名。泛指B站评论区里用企鹅头像、说话可爱又带点阴阳怪气的用户群体。
- **我的刀盾**：源自游戏圈梗，"我的刀盾呢"是玩家在被偷袭或需要战斗时的经典台词。在B站演变为任何"准备干架"或"防御"场景的弹幕。
- **你干嘛~哎哟**：蔡徐坤《偶像练习生》中"你干嘛"的魔性语调，B站最出圈鬼畜素材之一。配合篮球和背带裤成为"坤学"核心。
- **鸡你太美**：蔡徐坤《只因你太美》空耳，现象级鬼畜素材。因"鸡"谐音"只因"，衍生出海量二创。弹幕常刷"只因你太美"。
- **小黑子**：蔡徐坤黑粉的统称。源自"黑粉"的谐音，常用于调侃。例句："露出鸡脚了吧小黑子"。
- **金坷垃**：经典鬼畜素材，源自肥料广告"金坷垃"。美国人、日本人、非洲人争抢金坷垃的魔性对话。"金坷垃给他！""非洲农业不发达，必须要有金坷垃！"

### 弹幕文化
- **梦开始的地方**：指经典视频系列第一期或某个重要转折点。例句："鬼畜区梦开始的地方"。
- **镇站之宝**：播放量极高、公认B站代表作的视频。
- **你币没了**：UP主说了招黑内容时弹幕刷"你币没了"（你的硬币我要取消）。任何不爽操作的调侃。
- **下次一定**：UP主求三连时的白嫖经典回复。永远不会投币的借口。
- **前方高能**：B站最经典弹幕。源自《高达》"前方高能反应"。提醒后面有精彩/恐怖内容。衍生"前方核能""非战斗人员撤离"。
- **空降成功**：按弹幕时间戳跳到精彩部分。衍生"空难"（跳错）、"指挥部"（发时间戳的人）。
- **战歌起**：激动BGM响起时的弹幕。《βios》《Only My Railgun》等经典战歌。
- **开 口 跪**：某人一开口就让人跪服。嗓音极好或反差极大。
- **梦 幻 联 动**：两个不可能合作的人/品牌突然合作，弹幕刷"梦幻联动"。
- **双厨狂喜**：同时喜欢两个东西的人在联动或同框时狂喜。
- **禁止好活**：弹幕调侃"这活太好了，不许整这么好的活"。变体"禁止自娱自乐""这入是桂"。
- **这入是桂**："这个人是要跪"的谐音。形容让人佩服得五体投地。

### UP主与社区梗
- **蒙古上单**：B站传奇用户。在CEO陈睿动态下评论"你所热爱的就是你的生活"一战成名。被视为用户嘴替和精神领袖。
- **叔叔**：B站CEO陈睿的用户戏称。例句："叔叔我啊，最喜欢钱了"——调侃B站商业化。
- **百大UP主**：B站每年评选的Top100创作者。"百大暗杀名单"指百大获奖者后续常翻车。
- **咕咕咕/鸽了**：UP主拖更。"鸽子"叫声→咕咕咕→鸽了=拖更。
- **三连**：点赞+投币+收藏。UP主视频结尾必备台词："求三连！"
- **课代表**：评论区总结视频要点的人。"谢谢课代表"常刷弹幕。
- **省流助手**：帮不想看完整视频的人概括内容。"省流：xxx"。
- **满分作文**：评论区文采飞扬的长评。B站评论区常见押韵段子。
- **鬼畜区素材库**：调侃B站几乎所有内容都能被做成鬼畜。
